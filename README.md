Вариант 11: 

Найти строчку в массиве с минимальной суммой элементов. (N =5, M = 3) 

# Решение на С: 

В получившемся решении проводится 8 присваиваний, если не считать переменные счетчики при объявлении циклов из которых 5 это так же объявление переменных. 2 Цикла, один вложен в другой, для прохождения по элементам массива и 1 блок if-else для выявления строки с наименьшей суммой элементов. Так же при объявлении переменной минимальной суммы, первоначальным значением является максимально возможное значение типа int, это было сделано для сокращения кода. 


# Решение на языке ассемблера 
Карта регистров выглядит следующим образом: 
a0 - массив 
a1 - M, кол-во элементов в строке 
a2 - N, кол-во строк 
t0 - сумма 
t1 - наименьшая строка 
t2 - наименьшая сумма 
t3 - счетчик элементов в строке 
t4 - текущий элемент массива 
t5 - счетчик строк 

Прохождение по массиву осуществляется путем сдвига указателя на 4, пользуясь тем что элементы в массиве лежат подряд. Учет строк и элементов ведется счетчиками.

# Сравнением подходов 

Код на C был скомпилирован на компиляторе risc-v и из него был получен дамп. В основных отличиях дампа и кода написанного в ходе лабораторной можно отметить разные подходы к прохождению массива. В дампе циклы делают проверку в конце, а в моем решении проверка происходит в начале. Компилятор Си кода держит все в памяти, а мой код держит все в регистрах. Мой код короче в два раза так как нет обращений к стеку и пересчета адреса.
